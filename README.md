# 🐾 PAWS: Pet Adoption Welfare System

A full-stack web application designed to streamline stray animal rescue, shelter management, medical tracking, and pet adoption through a centralized digital platform.

## 📖 Overview
Pet Adoption Welfare System(PAWS) is built to support animal shelters, NGOs, veterinary teams, volunteers, and the public by providing a single platform to manage shelter operations efficiently. It digitizes rescue records, medical histories, adoption workflows, donations, and communication, promoting transparency and improving animal welfare. :contentReference[oaicite:2]{index=2}

## ✨ Features

### 👤 Public Users
- Browse pets available for adoption
- View detailed pet information
- Submit adoption requests
- Report stray animals
- Donate to shelters

### 🏠 Shelter Management
- Shelter registration and login
- Manage pet listings
- Update adoption status
- Track shelter capacity
- Manage shelter profile

### 🩺 Veterinary & Medical
- Vaccination tracking
- Medical history management
- Sterilization records
- Health monitoring

### 💬 Communication
- Shelter inbox
- User-shelter messaging
- Adoption inquiries

### 📊 Administration
- User management
- Shelter verification
- Donation tracking
- Activity management
- Role-based access

## 🏗️ System Architecture

```
React Frontend
      │
      ▼
Node.js + Express Backend
      │
      ▼
     MySQL Database
```

The frontend communicates with the backend through HTTP requests, while the backend performs CRUD operations on the MySQL database.

---

## 🗄️ Database Schema

The system includes the following major entities:

- Users
- Shelters
- Pets
- Donations
- Activities
- Vaccinations
- Messages

These tables are connected through relational mappings to maintain data integrity and efficient management.
